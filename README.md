# 🎓 Student Performance Prediction

An AI-powered web application that predicts a student's expected exam score using academic, personal, and learning-related factors.

## ✨ Features

- 🤖 Machine Learning based exam score prediction
- 📊 Model comparison
- 🏆 Automatic best model selection
- 📋 Prediction history
- 📈 Analytics dashboard
- 🤖 Model performance page
- 📄 Downloadable PDF report
- 📥 CSV export
- 🌙 Dark / Light mode
- 🧹 Clear prediction form
- 📱 Responsive user interface

## 🤖 Machine Learning Models

The project compares:

1. Linear Regression
2. Ridge Regression
3. Random Forest Regressor
4. Gradient Boosting Regressor
5. Extra Trees Regressor
6. Hist Gradient Boosting Regressor

The model with the lowest MAE is automatically selected.

## 📊 Evaluation Metrics

### MAE
Mean Absolute Error measures the average difference between actual and predicted values.

Lower MAE means smaller prediction errors.

### RMSE
Root Mean Squared Error measures prediction error and gives more importance to larger errors.

Lower RMSE indicates smaller errors.

### R² Score
R² indicates how much of the variation in the target variable is explained by the model.

## 📚 Dataset

Dataset used:

Student Performance Factors

Target variable:

Exam_Score

The dataset contains approximately 6,600 student records and 20 columns.

## ⚙️ Installation

### 1. Clone the Repository

After uploading the project to GitHub, copy your GitHub repository URL.

Example:

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Open the Project

cd "Student Performance Prediction"

### 3. Create Virtual Environment

python -m venv venv

### 4. Activate Virtual Environment

For Windows PowerShell:

venv\Scripts\Activate.ps1

### 5. Install Dependencies

pip install -r requirements.txt

## ▶️ Run the Project

Start the Flask application:

python app.py

Then open your browser:

http://127.0.0.1:5000

## 🔮 How to Use

1. Open the application.
2. Enter the student's information.
3. Click Predict Exam Score.
4. View the predicted score.
5. Check the performance level.
6. View the prediction summary.
7. Download the PDF report if required.
8. Open History to view previous predictions.
9. Open Dashboard to view prediction statistics.
10. Open Model Performance to compare ML models.
